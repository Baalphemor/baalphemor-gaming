# BAALPHEMOR GAMING — Offizielle Pre-Launch Landingpage (`baalphemor-gaming.de`)

Offizielle Pre-Launch Web-Präsenz für **BAALPHEMOR GAMING** ([baalphemor-gaming.de](https://baalphemor-gaming.de)), entwickelt von Michael Stahlschmidt (**BAALPHEMOR**).

## Die 4 kommenden Spiele-Projekte (Pre-Launch Vorschau)
1. **`Auritan: Grid of Fate`** — Taktisches Dark-Fantasy-Hex-TTRPG mit 2W12-Glockenkurve ([auritan.de](https://auritan.de)).
2. **`Auritan: Broadside`** — Eigenständiges maritimes Seekriegs- & Flottentaktik-Spiel.
3. **`Auritan: Empires`** — Eigenständiges Hex-4X-Aufbau- & Strategiespiel.
4. **`Auritan: Vanguard`** — Helden-zentrierte Echtzeit-Erkundung & Taktik (Hero-RTS).
